## 4. Previews and Screenshots

⚠️ **PALING WORK BERAT.** Wajib upload screenshot untuk minimum 1 device size. Recommended 2 size:

1. **HOME PAGE dengan hero banner** — Show splash brand + featured products. Tagline overlay: "Toko Hewan Peliharaan Medan Terpercaya"
2. **PRODUCT DETAIL** — Show product photo + price + reviews. Tagline: "Brand Original, Pengiriman Cepat"
3. **CART + CHECKOUT** — Show cart dengan multiple items. Tagline: "Checkout Mudah, Bayar Aman"
4. **ORDER TRACKING** — Show order status timeline. Tagline: "Lacak Pesanan Real-Time"
5. **MEMBER LOYALTY** — Show loyalty points & vouchers. Tagline: "Diskon Member Eksklusif"

### Cara bikin screenshot

**Opsi A — Take screenshot di iPhone real**
1. Buka Natalo di iPhone (via TestFlight Build 14)
2. Navigate ke halaman yang mau di-screenshot
3. Side button + Volume Up bersama → screenshot
4. Crop / edit di Photos app kalau perlu

**Opsi B — Use Xcode Simulator (butuh Mac, skip)**

**Opsi C — Online screenshot generators (recommended untuk Windows)**
1. Bikin screenshot di Safari mobile mode (Chrome DevTools → Device Mode → iPhone 14 Pro Max)
2. Atau pakai service [appstorescreenshot.com](https://appstorescreenshot.com) / [previewed.app](https://previewed.app):
   - Upload screenshot browser
   - Pilih iPhone frame
   - Tambah tagline text overlay
   - Download ukuran App Store

**Opsi D — Mockup tool (paling premium look)**
- Figma + iPhone mockup template (gratis)
- Atau Mockup.app, Smartmockups (paid)

### Format screenshot

Per Apple guideline:
- Format: **PNG** (recommended) atau JPEG
- Color space: sRGB or P3
- No alpha channel
- Bisa portrait atau landscape (portrait standard untuk e-commerce)

## 8. After Submit

Status berubah ke **Waiting for Review** → **In Review** → **Pending Developer Release** (atau **Ready for Sale** kalau pilih automatic).

| Status | Action |
|---|---|
| Waiting for Review | Tunggu Apple assign reviewer (~24 jam) |
| In Review | Apple reviewer test app (~24-48 jam) |
| Pending Developer Release | ✅ Approved! Klik "Release This Version" |
| Ready for Sale | 🚀 Live di App Store! |
| Rejected | 📋 Baca rejection note, fix, resubmit |

---

## Common Rejection Reasons & Fix

### 1. Sign-in Issues
- Akun demo gak bisa login → cek password masih valid
- App butuh phone OTP → reviewer gak punya nomor → kasih account yang sudah ter-verified

### 2. Privacy Compliance
- Privacy Policy URL gak accessible → cek `/kebijakan-privasi` masih live
- Missing data collection disclosure → update Privacy Manifest

### 3. Functionality
- App crash di certain flow → fix bug, resubmit
- Feature mentioned in description gak ada → adjust description ATAU implement feature

### 4. Design / Content
- Logo Apple di app (e.g., "Sign in with Apple" tanpa actual implementation) → remove atau implement
- Use of "Apple", "App Store", "iPhone" without Apple style guide compliance → fix

### 5. Web View Concerns
- App "just a web wrapper" tanpa native features → highlight native features yang sudah kita add (push notif, share sheet, camera, deep links, status bar adaptive, splash screen native)
- Mention itu di Notes for Reviewer

## Tips dari pengalaman

1. **First submission biasanya ke-reject** — Apple sangat detail, beberapa rejection wajar
2. **Reply rejection note dengan detail** — sebut spesifik feature/fix yang kamu kerjakan
3. **Jangan reset rejection** — gunakan resubmit dengan koreksi
4. **Screenshot quality > quantity** — 3 screenshot bagus lebih baik dari 10 mediocre
5. **Promotional text pakai emoji** — App Store lebih engaging dengan emoji di intro
6. **Localize semua** — Apple suka app yang explicitly support Indonesian, bukan just English fallback

## Yang HARUS kamu kerjakan untuk submit App Store

1. ☐ **Screenshots** — paling memakan waktu, 30 menit-2 jam tergantung tool
2. ☐ **Fill App Information** — text content sudah saya draft
3. ☐ **Age Rating questionnaire** — 13 questions, ~5 menit
4. ☐ **App Privacy** — collect data disclosure, bikin Privacy Manifest kalau perlu
5. ☐ **App Review Information** — copy dari section 5 di atas
6. ☐ **Add for Review** + tunggu 1-3 hari

Total effort: ~3-5 jam (mostly screenshot creation).

⚠️ **Sebaiknya tunggu external Beta Review approve dulu** (1-2 hari). App Store submission process beda dari Beta, tapi ada kemungkinan Apple lihat both queues. Kalau Beta di-reject, App Store submission juga akan kena delay/reject sambil mengurus Beta dulu.
