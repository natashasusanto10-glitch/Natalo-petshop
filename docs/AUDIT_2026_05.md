# Audit Hardening — Mei 2026

Comprehensive code audit dijalankan setelah landed-set:
- Push notifications (APNs/FCM/Web Push)
- Capacitor iOS native wrapper
- Order/checkout flow polish

Audit ini fokus ke 4 area: admin panel, checkout flow, mobile UX (PWA + native),
auth & session. Plus general hygiene (perf, error handling, dead code).

## Hasil

20 finding ditemukan (8 high, 8 medium, 4 low). 16 di-resolve dalam 3 batch
commit; 4 sisanya nits yang diterima sebagai trade-off atau false positive.

## Batch A — Security (commit `dd79df2`)

| # | Issue | Fix |
|---|---|---|
| A1 | CSRF gap di 7 admin endpoints (upload, reviews status/reply, products bulk, import, variants×2) — sebelumnya hanya `broadcast` + `products/reset` yang protected | Apply `assertSameOrigin` ke semua state-changing admin POST/PUT/PATCH |
| A2 | Push unsubscribe (`DELETE /api/push/subscribe*`) tanpa auth — siapapun bisa silent-unsubscribe device user lain kalau tau endpoint/token | Require CUSTOMER session + `deleteMany` scope by `userId` (sudah landed di `991ae12`) |
| A3 | Password reset tidak bump `User.tokenVersion` — sesi attacker di device lain tetap valid setelah victim reset password | `tokenVersion: { increment: 1 }` di transaction reset-password |
| A4 | Magic-byte validation hilang di customer upload (`payment-proof`, `reviews/upload`) — admin/viewer rentan XSS via SVG polyglot dgn Content-Type spoofed | Call `validateImageMagicBytes(buffer, file.type)` sebelum upload ke UploadThing |
| A5 | Google Maps endpoints (`autocomplete`, `details`, `reverse-geocode`) anonymous + no rate limit — cost-DoS vector ke billing Google | `getMapsLimiter`: 30 calls/menit per IP via Upstash |
| A6 | AI product-assistant login-required tapi no rate limit — 1 user bisa loop POST → burn OpenAI budget | `getAiLimiter`: 20 calls/jam per `userId` |

## Rate limit summary post-audit

Semua endpoint yang call paid external API atau punya abuse vector sekarang
rate-limited via Upstash Redis (`lib/rate-limit.ts`):

| Limiter | Window | Limit | Used by |
|---|---|---|---|
| `getLoginLimiter()` | 15 min | 10 attempts | member-login, admin-login (per IP) |
| `getOtpLimiter()` | 10 min | 5 attempts | member-register OTP, forgot-password (per IP) |
| `getMapsLimiter()` | 1 min | 30 calls | places autocomplete/details/reverse-geocode (per IP) |
| `getAiLimiter()` | 1 jam | 20 calls | ai/product-assistant (per userId) |

Fallback graceful: kalau `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN`
belum di-set, `checkLimit()` return `{ ok: true }` (no-op) supaya dev tidak block.

## Verifikasi production

Setelah Vercel deploy selesai:

1. **Rate limit aktif:** spam endpoint dari satu IP → response 429 dengan
   header `Retry-After`. Cek Upstash Data Browser → keys `rate:login:*`,
   `rate:otp:*`, `rate:maps:*`, `rate:ai:*`.
2. **CSRF guard:** POST ke admin endpoint dgn `Origin` cross-domain →
   403 "Forbidden — invalid Origin".
3. **Password reset force-logout:** reset password di Device A → cek sesi
   Device B → next API call kena 401 (tokenVersion mismatch).
4. **Guest checkout protection:** checkout sbg guest dgn email registered
   user → order BARU (tidak attach ke registered account).
